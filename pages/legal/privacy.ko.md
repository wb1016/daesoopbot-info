# 대숲봇 개인정보 처리방침

**시행일: 2026-09-24**

대숲봇(영문명: bamboozleify-bot, 이하 "봇")은 디스코드 내 익명 메시지 중계 서비스입니다. 이 문서는 봇이 처리하는 개인정보(디스코드 계정 정보)의 항목, 목적, 보관 기간, 이용자의 권리를 설명합니다.

## 제1조 수집하는 정보

봇은 다음 정보를 수집하여 봇 운영자가 관리하는 데이터베이스에 저장합니다.

| 항목 | 내용 | 목적 |
|---|---|---|
| 디스코드 사용자 ID | 익명 메시지 작성자 식별용 고유 번호(눈송이 ID) | 운영자의 "작성자 보기" 요청 처리, 차단 관리 |
| 디스코드 서버·채널·메시지 ID | 익명 메시지가 게시된 위치 식별 | 작성자와 메시지 연결, 데이터 관리 |
| 게시 시각 | 익명 메시지 작성 시각 | 보존 기간 관리, 운영 기록 |
| 제출된 콘텐츠 | 이용자가 작성한 텍스트와 첨부 파일 | 이용자의 요청대로 채널에 게시 |
| 쿨다운 기록 | 마지막 게시 시각 | 스팸 방지 |
| 차단 기록 | 차단된 사용자 ID, 사유, 조치한 운영자 ID, 시각 | 차단 관리 및 운영 감사 |

또한 봇은 상호작용 처리를 위해 디스코드가 전달하는 일시적 상호작용 데이터(명령어 사용 기록, 버튼 클릭 등)를 처리합니다. 이는 디스코드 플랫폼 동작의 일부로, 봇이 별도로 저장하지 않습니다.

## 제2조 수집하지 않는 정보

- IP 주소, 이메일 주소, 전화번호 등 디스코드 계정 세부 정보
- 봇이 게시하지 않은 일반 채팅 내용 (봇은 메시지 콘텐츠 읽기 권한을 사용하지 않습니다)
- 쿠키, 광고 추적, 분석 도구 (봇은 웹 서비스를 운영하지 않습니다)
- 비밀번호, 결제 정보 등 그 외 모든 개인정보

## 제3조 이용 목적

1. 익명 메시지 게시 및 확인 응답 제공
2. 서버 운영자의 운영 조치(작성자 확인, 타임아웃, 차단) 지원 및 감사 기록
3. 스팸·도배 방지 (쿨다운)
4. 서비스 오류 진단

봇은 위 목적 외로 개인정보를 이용하지 않으며, 광고·마케팅에 이용하지 않습니다.

## 제4조 보관 위치와 보존 기간

1. 데이터는 대한민국 내 Oracle Cloud 인프라(한국 리전)에서 운영되는 서버의 SQLite 데이터베이스에 저장됩니다.
2. **익명 메시지 작성자의 사용자 ID는 기본 30일이 지나면 데이터베이스에서 삭제(익명화)됩니다.** 이후에는 해당 메시지의 작성자를 봇이 알 수 없게 됩니다.
3. 게시된 메시지 본문과 첨부 파일은 디스코드의 서버에 저장되며, 해당 서버의 운영자가 삭제할 때까지 유지됩니다. 봇은 이를 별도로 복사해 두지 않습니다.
4. 차단 기록은 차단이 해제될 때까지 보관됩니다.

## 제5조 정보의 제공 및 노출

1. 봇은 개인정보를 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.
2. **서버 운영자에게의 노출:** 익명 메시지 작성자 정보는 해당 서버의 운영자가 "작성자 보기" 버튼을 눌렀을 때, 해당 운영자에게만 일시적으로(에페머럴 메시지로) 표시됩니다. 타임아웃·차단 등 운영 조치 기록은 서버가 지정한 운영 로그 채널에 기록될 수 있습니다.
3. 법령에 따라 수사기관 등으로부터 적법한 요구가 있는 경우, 관련 법령이 정하는 범위에서 정보가 제공될 수 있습니다.
4. 봇은 디스코드 플랫폼 위에서 동작하므로, 디스코드(Discord Inc.)의 개인정보 처리는 디스코드의 개인정보 처리방침을 따릅니다.

## 제6조 이용자의 권리

이용자는 자신의 개인정보에 대해 다음을 요구할 수 있습니다.

1. 열람, 정정·삭제, 처리 정지
2. 익명 메시지 작성 기록의 즉시 익명화(보존 기간 전이라도)

요청 방법: `cobaltdev@sudden.ninja` 또는 해당 디스코드 서버의 운영자에게 문의하세요. 서버 단위 데이터(차단 기록 등)는 해당 서버 운영자가 관리하므로, 서버 관련 사항은 서버 운영자에게 요청하는 것이 신속합니다.

## 제7조 만 14세 미만 이용자

봇은 대한민국 법령에 따라 만 14세 미만 이용자의 개인정보 수집·이용에 대한 동의를 받을 수 없습니다. 만 14세 미만인 이용자는 봇을 사용하지 않아야 합니다.

## 제8조 처리방침의 변경

본 처리방침이 변경되는 경우 변경된 문서가 게시되는 즉시 효력이 발생합니다. 중대한 변경 사항은 [GitHub 커밋 역사](https://github.com/wb1016/daesoopbot-info/commits/main/pages/legal/privacy.ko.md)에서 기록을 볼 수 있습니다.
