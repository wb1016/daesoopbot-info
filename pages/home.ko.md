# 대숲봇

대숲봇은 디스코드 서버를 위한 **익명 메시지 중계 봇**입니다. 서버 구성원이 작성자를 드러내지 않고 메시지와 미디어(사진·동영상·오디오)를 채널에 올릴 수 있게 해 주면서, 운영진에게는 안전한 운영 도구를 제공합니다.

## 대숲봇은 무엇을 하나요?

- `/bamboo` 명령어로 나만 볼 수 있는 작성 창을 열고, 텍스트와 파일을 담아 전송하면 봇이 **작성자 정보 없이** 해당 채널에 게시합니다.
- 게시된 메시지에는 운영진 전용 버튼이 붙습니다:
  - **작성자 보기** - 운영진만 그 메시지의 실제 작성자를 확인할 수 있습니다 (운영진 본인에게만 표시됨).
  - **관리** - 문제를 일으킨 사용자에게 타임아웃을 주거나, 대숲봇 사용을 영구 차단할 수 있습니다.
- 차단·타임아웃 등 운영 조치는 서버가 지정한 **운영 로그 채널**에 기록으로 남습니다.
- 작성자 신원 기록은 기본 30일이 지나면 자동으로 삭제(익명화)됩니다.

자세한 내용은 [이용약관](/terms)과 [개인정보 처리방침](/privacy)을 참고해 주세요.

## 서버에 초대하기

서버의 관리자가 아래 링크를 열어 초대하면 됩니다. 초대 시 봇에 필요한 권한(채널 보기, 메시지 보내기, 파일 첨부, 멤버 제한 시간 설정)이 미리 선택되어 있습니다.

**[초대 링크](https://discord.com/oauth2/authorize?client_id=1552626227964018758&scope=bot+applications.commands&permissions=1099511663616
)**

초대 후에는 서버 관리자가 한 번만 설정하면 됩니다:

1. `/bamboo-setup modrole` - 운영 버튼을 사용할 역할 지정 (드롭다운에서 선택)
2. `/bamboo-setup modlog` - 운영 기록이 쌓일 채널 지정 (선택)
3. `/bamboo-setup cooldown` - 사용자당 전송 간격(초) 지정 (선택, 0이면 비활성화)

## 사용 방법

### 메시지 익명으로 보내기

1. 익명으로 올리고 싶은 채널에서 `/bamboo` 입력
2. 나타나는 작성 창에 내용 입력:
   - **메시지** - 보낼 텍스트 (최대 2,000자)
   - **미디어** - 사진·동영상·오디오 파일 (최대 10개, 파일당 10MiB까지)
3. **제출** - 봇이 그 채널에 익명 메시지를 게시하고, 나에게만 보이는 확인 메시지로 링크를 알려줍니다.

텍스트와 파일은 둘 중 하나만 있어도 됩니다. 같은 사용자가 연속으로 너무 빠르게 보내면 쿨다운이 걸릴 수 있어요.

### 운영진 기능

게시된 익명 메시지의 버튼으로 사용합니다. 운영 역할이 있거나 **메시지 관리** 권한이 있는 멤버만 동작합니다.

- **작성자 보기** - 누가 보냈는지 확인 (본인 화면에만 표시)
- **관리** → **타임아웃** - 디스코드 타임아웃 (1시간 ~ 28일)
- **관리** → **영구 차단** - 그 사용자의 대숲봇 사용 차단
- **관리** → **취소** - 아무것도 하지 않고 닫기

명령어로도 관리할 수 있습니다:

| 명령어 | 설명 |
|---|---|
| `/bamboo-mod block <사용자> [사유]` | 미리 차단하기 |
| `/bamboo-mod unblock <사용자>` | 차단 해제 |
| `/bamboo-mod blocked` | 차단 목록 보기 |
